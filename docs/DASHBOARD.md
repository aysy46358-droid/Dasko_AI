# لوحة متابعة Dasko AI

آخر تحديث: 2026-11-10. هذه لوحة متابعة تشغيلية موجزة؛ المرجع التفصيلي لحالة المشروع هو `docs/PROJECT_CONTROL.md`، ووصف البنية وجرد الملفات في `docs/PROJECT_MAP.md`.

## حالة الوكلاء

| الدور/الوكيل | الحالة | الملاحظة |
|---|---|---|
| المالك | بانتظار المراجعة | يزوّد نص `AGENTS.md` النهائي، ثم يراجع PR وقرار الدمج. |
| Manus | ينفّذ على `agent/phase-0-infra-fixes` | التغييرات قيد المراجعة والتحقق؛ إنشاء `AGENTS.md` والـPR ينتظران النص النهائي من المالك. لا دمج إلى أي فرع. |
| Claude (مراجع خارجي) | التدقيق مستلم | نتائج التدقيق أُخذت كمدخلات للمهمة، وليست بديلاً عن تحقق الكود والـCI. |

## تقدم المراحل

| المرحلة | الحالة | معيار الإغلاق |
|---|---|---|
| Phase 0.1 — بوابة PR إلى `experimental-work` | قيد التنفيذ | `pub get --enforce-lockfile`، `gen-l10n`، format، analyze، tests، وفحص خريطة المشروع تعمل على PR. |
| Phase 0.2 — فصل الاعتمادات | قيد التنفيذ | لا تستورد الميزة `app/providers.dart`، ولا يستورد `chat_screen.dart` شاشة الإعدادات؛ مزودات المحادثة في الميزة، وربط المحرك في جذر التطبيق. |
| Phase 0.3 — حجز `versionCode` | قيد التنفيذ | الحجز وإنشاء tag يحدثان عند `workflow_dispatch` فقط؛ push يستخدم قيمة `pubspec.yaml` الحالية دون تعديلها. |
| Governance — `AGENTS.md` | معلّق على المالك | لا يُنشأ الملف ولا يُستبدل بمسودة حتى يصل النص النهائي المحدد من المالك. |
| Phase 1 — Gemini / Firebase AI Logic | لم تبدأ | تبدأ فقط بعد إغلاق Phase 0 ودمج المالك، مع إبقاء المفتاح خارج التطبيق وعدم الترقية إلى Blaze. |

## المخاطر والقيود

- وجود workflow جديد لا يجعل فحوص PR إلزامية للدمج تلقائياً؛ إعدادات حماية الفرع وrequired status checks في GitHub تحتاج تحققاً/تغييراً منفصلاً وموافقة المالك.
- `format_experimental.yml` في هذا الفرع فحص تنسيق فقط؛ أي تنسيق غير مطابق يفشل بدلاً من تعديل الفرع أو دفع commit تلقائياً.
- لا يوجد Flutter SDK في بيئة التنفيذ الحالية؛ لذلك لا يُدّعى نجاح `flutter analyze` أو `flutter test` محلياً. يجب إثباتهما من تشغيل PR Actions قبل طلب المراجعة النهائية.
- لا تُعدّل أرقام الإصدار المحفوظة حالياً، ولا يُدمج PR آلياً. إصدار الإنتاج وتحديد `versionCode` النهائي يظلان قراراً لاحقاً.
- إعداد Firebase Console وApp Check، وسلوك App Check على جهاز حقيقي، وتكامل Gemini الفعلي خارج نطاق Phase 0.
